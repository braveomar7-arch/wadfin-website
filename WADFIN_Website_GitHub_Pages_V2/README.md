# WADFIN Website — GitHub Pages Ready

This is a static website for the West African Digital Forensics & Investigations Network (WADFIN).

## Important positioning

The site intentionally presents WADFIN as being in its **founding phase**. This protects credibility while governance, legal registration, formal membership structures and partnerships are being established.

- Home
- About
- Our Work
- Research & Resources
- Membership
- Partnerships
- Governance & Ethics
- Contact

## Local preview

Open `index.html` in a browser.

For best results, use a simple local web server:

```bash
python -m http.server 8000
```

Then browse to `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `wadfin-website`.
2. Upload **the contents of this folder**, not the ZIP itself.
3. Commit the files.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save.
8. GitHub will provide the public `github.io` address.

## Before final public launch

Recommended additions when available:

- official organisational email address;
- confirmed legal entity / registration details;
- final membership rules;
- privacy notice;
- cookie notice if analytics are added;
- final Evidence & Ethics Charter;
- named Steering Group / Advisory Council;
- verified partner logos only after formal approval;
- final GitHub links for TraceFrame and ChronoTrace;
- analytics / SEO setup;
- custom domain.

## No backend

This GitHub Pages version is fully static. It deliberately does not include a contact form that pretends to send information without a backend. WhatsApp and telephone actions are functional.

For a later contact form, connect a service such as Formspree or deploy a small serverless endpoint after deciding the organisation's privacy/data-retention policy.
